# 安全报告 / Security reports

使用权限、审批、数据保存和发行限制见 [安全文档](docs/SECURITY.md)。

如果发现漏洞，请使用本仓库 **Security → Report a vulnerability** 私密提交。请描述影响、受影响版本和最小复现步骤。请勿在公开 Issue 中上传本机配置、日志、token、个人应用数据或可直接利用的细节。

Please use **Security → Report a vulnerability** for private disclosure. Include the affected version, impact and a minimal reproduction. Do not attach local state, credentials, personal application data or exploitable details to public issues.
